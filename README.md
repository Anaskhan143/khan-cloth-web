# Khan Cloth Web

Public marketing site for **Khan Cloth and Tailoring Shop** — fabric catalog + WhatsApp orders.

## Stack
- React + Vite + TypeScript
- Static fabric data (`src/data/fabrics.ts`)
- WhatsApp deep links (no backend yet)

## Run
```bash
npm install
npm run dev
```
